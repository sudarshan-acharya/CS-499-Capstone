CS-499 Computer Science Capstone

My capstone project builds upon the Event Tracking Android application originally developed in CS-360. The goal was to improve the application's design, functionality, algorithms, and database management through three enhancement categories.

Milestone One: Code Review

Before making enhancements to the application, I reviewed the original Event Tracking application to understand its existing structure, functionality, and areas that could be improved. The code review helped me identify opportunities to improve software design and engineering, algorithms and data structures, and database management.

The review served as the starting point for the enhancements completed throughout my CS-499 Capstone.

Enhancement 1: Software Design and Engineering

Status: Completed - Meets Expectations

  • Introduced EventRepository and EventViewModel.
  • Separated database operations from screen responsibilities.
  • Improved application navigation.
  • Added event deletion confirmation.

This enhancement improved how the application is organized and made it easier to manage its different responsibilities.

Enhancement 2: Algorithms and Data Structures

Status: Completed

  • Implemented Trie-based event-name prefix searching.
  • Added case-insensitive searching.
  • Added All, Upcoming, and Past event filters.
  • Improved event list usability and interface layout.
  • Added automated unit tests for Trie functionality.

This enhancement improved how users search for and organize events. I implemented and tested the Trie-based search and filters, including searching with different capitalization and searching for no matches.

Enhancement 3: Databases

Status: Completed

  • Implemented password hashing.
  • Improved database migration.
  • Enabled foreign-key enforcement.
  • Improved data integrity.

This enhancement focused on improving database security and making the application better at protecting user information and maintaining its data.
